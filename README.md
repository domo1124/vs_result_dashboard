# ポケモン対戦データ管理・解析スクリプト群

ポケモン対戦データ管理・解析スクリプト群
ゲーム画面の録画データ移動から、選出画面のスナップショット取得、Gemini APIを使用したパーティ検出、および結果確認までを自動化するためのユーティリティスクリプト群です。

共通仕様
サポートする日付フォーマット
日付を指定する引数では、以下のいずれのフォーマットも使用可能です。

%Y%m%d (例: 20260520)

%Y-%m-%d (例: 2026-05-20)

%Y/%m/%d (例: 2026/05/20)

各スクリプトの詳細
1. ディレクトリ作成 (setup_dir_season.py)
開催シーズン単位で、データ格納用の作業ディレクトリを生成します。

```bash
python setup_dir_season.py [シーズン名] [開始日] [終了日]
```

引数:

シーズン名: 作成するシーズン名（例: Season30）

開始日: シーズンの開始日

終了日: シーズンの終了日


2. 録画ファイル移動 (recording_mp4_move.py)
ゲーム画面の録画映像（.mp4）を作業用ディレクトリへ自動で振り分けます。

```bash
python recording_mp4_move.py
```

仕様: ファイル名のプレフィックス（先頭部分）に含まれる日付を読み取り、該当する日付の作業ディレクトリ内へ自動的に移動します。

3. 選出スナップショット取得 (party_snap_get_videos.py)
切り分けた対戦動画から、対戦相手の選出画面（パーティ一覧）のスナップショットを自動取得します。

```bash
python party_snap_get_videos.py [対戦日]
```

仕様: 指定された 対戦日 の動画を対象に、開始から2秒後のフレームをスナップショットとして切り出します。

4. Geminiによるパーティ検出 (party_snap_extract_gemini.py)
取得した選出画面のスナップショットをGemini APIに投入し、画像の上から順番に相手のパーティ内のポケモンを検出してJSON形式で出力します。

```bash
python party_snap_extract_gemini.py [対戦日]
```

出力JSONフォーマット
解析結果は以下のようなJSON構造で出力されます。
```json
[
{
"vs_date": "対戦日",
"pokemon_1": "ポケモン1",
"pokemon_2": "ポケモン2",
"pokemon_3": "ポケモン3",
"pokemon_4": "ポケモン4",
"pokemon_5": "ポケモン5",
"pokemon_6": "ポケモン6"
}
]
```

5. JSONデータ確認ユーティリティ (view_party_snap_json.py)
party_snap_extract_gemini.py によって出力された解析済みのJSONファイルの内容を、手軽に確認・チェックするためのスクリプトです。

```bash
python view_party_snap_json.py
```
